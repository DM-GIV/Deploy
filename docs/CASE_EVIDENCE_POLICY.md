# Стандарт публикации кейсов

Сайт разделяет три класса материалов, чтобы не выдавать объявления за завершённые сделки.

## 1. Исследованные публичные лоты (PUBLIC_LOT_RESEARCH)

**Подтверждаем:** ЭТП, URL процедуры, номер торгов, номер/состав лота, начальную цену на дату изучения, доступные сведения о документах и рисках.

**Не утверждаем без доказательства:** результат торгов, фактического покупателя, завершённость сделки, рыночную стоимость, прибыль или оказание нами услуги.

**Состояние:** десять примеров опубликованы на `/primery-lotov/`; сведения о происхождении и дате исследования хранятся в `content/research-cases.json`.

## 2. Документально подтверждённые сделки (DOCUMENTED_TRANSACTION)

Минимум для публикации:
- договор с различимой стадией: проект / подписан / исполнен;
- ссылка на процедуру и сопоставление её реквизитов с договором;
- протокол итогов либо иные документы, подтверждающие конкретные факты;
- подтверждение оплаты, передачи или перехода права — если такие утверждения делаются;
- подтверждение нашего участия, если страница называется «наш кейс»;
- разрешение на публикацию информации; исключение персональных, банковских, паспортных и прочих непубличных данных.

Наличие текста договора само по себе **не подтверждает**, что оплата произведена, имущество передано или работа выполнена нашей командой.

**Состояние:** готовых для публичного размещения материалов пока нет.

## 3. Завершённые проекты (COMPLETED_PROJECT)

Нужно описать:
- исходную задачу;
- наши подтверждённые действия;
- пройденные контрольные точки;
- результат с доказательствами;
- длительность и расходы только при наличии надёжных данных;
- ограничения результата и согласие на публикацию.

**Состояние:** не опубликованы, поскольку полный набор доказательств не подтверждён.

## Правила

Публикуем минимальные необходимые сведения. Статусы «изучено», «договор подписан», «оплачено», «передано» и «право зарегистрировано» не взаимозаменяемы.

Не публикуем оригинальные частные договоры, персональные реквизиты или документы из закрытых проектов без согласования.
