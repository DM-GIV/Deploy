# AI-поиск лотов: MVP и ограничения (14.10.2026)

## Что готово
- Новый маршрут `/ai-poisk-lotov/` и пункт меню после «Главная», независимо от услуги `/poisk-imushchestva/`.
- Форма свободного запроса, фильтр источника, максимум 10 кандидатов, карточки только со ссылками из допускаемых источников, переход к услуге проверки.
- Прямая навигация в ЕФРСБ и ГИС Торги и адресные поисковые запросы через Яндекс. Поисковая выдача не считается доказанной подборкой.
- Серверный Vercel Node API `/api/ai-lot-search`, **выключен по умолчанию**. Это не публичный вызов приватного V2 MCP.
- Страница временно `noindex,follow` и отсутствует в sitemap до приёмки работающего поиска.

## Состояние и источники
P0: ЕФРСБ — банкротство; ГИС Торги — арестованное и другие государственные/муниципальные имущественные торги.
P1: ЭТП и коммерческие продажи (МЭТС, Lot-online как первые адаптеры).
Единица выдачи — публикация/процедура/лот со ссылками; одно имущество может продаваться в повторной процедуре. Не склеивать без проверяемого ключа.
Автоматические предложения являются кандидатами; статус, цена, сроки и скидка без независимой первичной проверки не подтверждены.

## Контракт
`GET /api/ai-lot-search`: `{"enabled":false,"max_results":10}`.
`POST /api/ai-lot-search`: `{"query":"...","source":"all|bankruptcy|government|commercial","limit":5|10}`.
Положительный ответ: `{"ok":true,"lots":[{"title":"...","url":"https://...","region":null,"price_rub":null,"deadline":null,"summary":null}],"retrieved_at":"...","status":"PRELIMINARY_UNVERIFIED"}`.
Ссылки в JSON проходят whitelist hosts + совпадение с URL citation/source из Responses web_search. Даже такая проверка НЕ доказывает достоверности полей лота.
В случае отключения API возвращает 503 без запроса к OpenAI; UI показывает обычные источники и честное предупреждение.

## Условия активации
Нельзя включать без отдельного подтверждения:
1. `AI_LOT_SEARCH_ENABLED=true`, `AI_LOT_SECURITY_APPROVED=true`, `AI_LOT_LEGAL_APPROVED=true`, `OPENAI_API_KEY`, `AI_LOT_MODEL` (название проверенной модели).
2. Реальный постоянный распределённый rate limit / CAPTCHA и дневной денежный лимит; текущий API сам по себе их НЕ реализует.
3. Юридическая проверка передачи публичных запросов третьему лицу и текста политики обработки данных.
4. Испытания поиска, антигаллюцинаций, прав использования официальных источников и обработки сбоев.
5. Проверка того, что production действительно выполняет Vercel Node functions: Selectel VPS при самостоятельном статическом размещении требует отдельного серверного API / reverse proxy.
6. Продуктовая приёмка с пользователем; затем убрать `noindex`, внести маршрут в sitemap.

## Следующая архитектура
Серверный Lot Discovery API, модуль адаптеров ЕФРСБ/ГИС и коммерческих источников, нормализация/дедупликация, TTL/verification, очередь задач, кэш запросов, аудит расходов.
Auction Analytics подключать исключительно по read-only API с freshness gate, не напрямую из браузера.
V2 использовать для тестирования и исследования источников, а не передавать его пользовательскую сессию на публичный сайт.
