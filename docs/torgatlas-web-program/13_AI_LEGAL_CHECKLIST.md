## Решение владельца (зафиксировано 2026-10-15, это НЕ юридическое заключение)
Владелец (сообщение TORGATLAS-AI-BETA-LAUNCH-001) подтвердил намерение запустить ограниченную публичную beta AI Web Search на torgatlas.ru
с источниками УТПЛ, УЭТП и Центр реализации при соблюдении выявленных условий доступа, robots.txt и ограничений частоты запросов.
Владельцу известно: полный юридический анализ оферт площадок не завершён; эвристическое удаление персональных данных не гарантирует
отсутствия всех персональных сведений. Разрешение дано в пределах этого остаточного риска; нарушать установленные запреты и игнорировать
обнаруженные утечки не разрешено. SECURITY_REVIEW: PASS ставится только по результатам реальных проверок, а не на основании этого решения.

Ограничение метода: проверены только страницы регламентов и robots.txt; отдельные договоры оферты и закрытые документы не анализировались.
Регламенты ЭТП по банкротству — это правила проведения торгов (Приказ Минэкономразвития № 495); положения об открытой публикации
подтверждают публичность сведений, но не являются явным разрешением на автоматизированный сбор.

## Персональные данные (реализовано в коде и проверено на живых данных)
- В API/кэше/выдаче не остаются: ФИО (в любом падеже, с отчеством), инициалы с фамилией, имя после слов «должник/гражданин/ИП…», ИНН/СНИЛС/ОГРНИП,
  12-значные номера, паспорта, телефоны, e-mail → заменяются маркерами `[ФИО скрыто]`, `[идентификатор скрыт]` и т. п.
- Выдаётся: название имущества, идентификатор лота, цена, процедура, срок заявок, дата проверки, ссылка на первоисточник.
- Тексты запросов и лотов не логируются (демон пишет только строки старта), UI не использует storage/аналитику для запроса;
  кэш — только память процесса (5 мин, ограничен), страница `noindex`.
- Остаточный риск: редактирование эвристическое (имена без отчества вне контекста, адреса физлиц могут остаться); в источнике по ссылке данные видны как опубликованы.

- [x] Только публичные страницы без авторизации, CAPTCHA, закрытых баз и аккаунтов.
- [x] Запросы идентифицируются User-Agent со ссылкой на страницу сервиса.
- [x] Нагрузка на источники ограничена: пейсинг по robots, кэш страниц, лимиты на IP, ≤2 одновременных поиска.

- [x] Результаты и запросы не хранятся постоянно; LLM не используется; beta-уведомление на странице.
- [x] Персональные данные физических лиц скрываются на входе в кэш и на выходе API.
- [ ] Юридическая проверка соглашений/оферт площадок и достаточности редактирования ПДн — **не проводилась**.
