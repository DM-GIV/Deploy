# Пост-релизный пакет Core-поиска (TORGATLAS-AI-CORE-POST-RELEASE-005) — 2026-10-15

## LOT_TITLES_ROOT_CAUSE
Источник (ЕФРСБ, Tender Technologies) публикует у лота краткое «название» из одного номера: `lots.title = "Лот №4."`, а само имущество — в `lots.description` («Лот №4. Полуприцеп бортовой СЗАП 9327 (VIN…, ГРЗ…, местонахождение…)»). Мой поисковый сервис читал только `title` (описание я не запрашивал и в изолированном срезе его не копировал), поэтому карточки получали «Лот №N». Это свойство данных, а не классификатора: у 2 520 из 201 464 открытых лотов (1,25%) заголовок — только номер лота (ЕФРСБ 2 125, ГИС Торги 395). У всех 2 125 ЕФРСБ-лотов есть описание вида «Лот N. …»; у ГИС Торги — описание вида «Право заключения договора управления многоквартирным домом».
Исправление (минимальное, в поисковом контейнере, структура и данные Core не менялись): для заголовка, состоящего только из номера, берётся сохранённое описание — снимается собственный префикс «Лот №N.», текст обрезается до первой скобки (там VIN, ГРЗ, местонахождение), добавляется « — лот №N». Нет пригодного описания → «<тип имущества> — лот №N» (марка/модель не придумываются). Информативные заголовки не трогаются. Дубликаты теперь определяются по отображаемому заголовку (разные лоты с одинаковой ценой не схлопываются). Результат на живом сайте: «Полуприцеп бортовой СЗАП 9327 — лот №4», «Прицеп СЗАП 8357-02 — лот №9», «Полуприцеп тяжеловоз ТСП 94183-0000010 — лот №7», «Полуприцеп - тяжеловоз ЧМЗАП 9906 — лот №11».
Побочная находка (privacy) и её исправление: у обычных заголовков легковых в названии стояли VIN и госномер («VIN: X9FK…, гос. рег. номер: Т479РЕ73»). Правила маскирования дополнены: VIN, госномера легковых/мотоциклов и ГРЗ прицепов маскируются (`[VIN скрыт]`, `[номер ТС скрыт]`) во всём, что показывает сайт; тесты, включая защиту от ложных срабатываний (кадастровые номера, площади, годы).
