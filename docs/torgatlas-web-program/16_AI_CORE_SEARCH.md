## Контракт и защита Core-эндпоинта
- Вход — только структурированный фильтр (enum типов/процедур, список регионов из белого списка, цена, ≤5 ключевых слов, даты срока, limit ≤10); неизвестное поле → 422; нет SQL и произвольных колонок/сортировки; все значения — bound-параметры.
- Аутентификация: `Authorization: Bearer`, сравнение SHA-256 с `PUBLIC_SEARCH_TOKEN_SHA256` (constant-time); без переменной эндпоинт отвечает 404. Cookie/админ-сессия не принимаются.
- Транзакция `READ ONLY`, `statement_timeout 5 с`, `lock_timeout 0,5 с`, `max_parallel_workers_per_gather=1`, не более 2 одновременных запросов (иначе 503 BUSY), ограниченное окно кандидатов (400 + 3000 новейших лотов без срока).
- Наружу — только белый список полей карточки: название, категория, регион, цена со смыслом, процедура, статус/уровень подтверждения, срок, дата проверки, ссылка и её хост. Внутренних id, `source_data`, участников, ИНН, документов нет (тест и проверка ответа).
- Строгое AND по всем заданным признакам; отсутствие поля = лот не подходит. Лоты без лот-уровневой https-ссылки (корень сайта, `/backend/`, http, учётные данные) не выдаются. Дубли (название+цена+регион) схлопываются.
- Свежесть: только `APPLICATION_OPEN` и аукцион не отменён/не «анонсирован». Уровни: 0 — срок в будущем и проверка ≤14 суток; 1 — срок в будущем, давно не проверялось; 2 — срока нет, но проверено ≤14 суток (в карточке «срок не подтверждён»). Просроченные и «без срока и давно не проверенные» не выдаются.
- Цена: «Цена текущего периода» только при действующем периоде публичного предложения; иначе «Начальная цена лота по данным каталога».

## Парсер запросов (без LLM)
Тип/подтип/синонимы (квартира, нежилое, гараж, склад, легковой/грузовой/автобус, прицеп/автоприцеп/полуприцеп с различением через ключевое слово в названии, спецтехника …), субъект РФ в любых падежах, федеральный округ и аббревиатуры (ЮФО, ПФО …), цена (до/от/диапазон, тыс./млн), вид процедуры, срок («до 30 ноября», «в ближайшие 7 дней»). Всё названное — строгие условия; неоднозначная география («в Сибири», «на Урале») или неопределённый тип → просьба уточнить, а не широкий поиск. «Поволжье» ≠ ПФО: явный список (Астраханская, Волгоградская, Пензенская, Самарская, Саратовская, Ульяновская области, Калмыкия, Татарстан), он показывается пользователю. Город даёт только регион (с пометкой). Нераспознанные слова показываются как «не учтено».

## ALTCHA (production, проверено)
Отдельный ключ AI-поиска (в `/home/deploy/torgatlas-ops/ai-search.env`, 0600; не равен ключу форм заявок; формы не менялись). Протокол v1, вектор совместим с Python-реализацией форм. Проверка **до** разбора запроса и любого поиска; токен одноразовый (память процесса), параллельное использование — выигрывает один запрос; срок 5 мин; токен, выданный до старта процесса, отклоняется; выдача ограничена 30/мин на IP; без ключа при `REQUIRED=true` — fail-closed 503. Сохранены Origin, лимиты nginx (2/мин/IP, 1 соединение), SSRF-защита, лимиты тела.
Проверено: без токена 403 CAPTCHA_REQUIRED; мусорный токен — CAPTCHA_INVALID; самодельный challenge — INVALID; повтор — CAPTCHA_REPLAY; параллельно один токен — обслужен один; просроченный — EXPIRED (юнит); в браузере поле доступно сразу, текст сохраняется при любой ошибке CAPTCHA, виджет сбрасывается после каждого поиска.

## Блокеры подключения Core в production (точные)
1. **Развёртывание расширения Core**: нужно собрать образ `auction-data004` из `16880db` и пересоздать `aa-data004-api-1` (секунды недоступности админ-каталога) — это изменение общего production-сервиса, требует решения ops-владельца Core. Я не менял Core, его compose, секреты, БД.
2. **Сетевой путь**: `ai-search` сидит в internal-сети без выхода; Core слушает 127.0.0.1:18004 и tailscale. Нужен утверждённый путь (например, подключение API Core к сети `ta_ai_internal` либо отдельный loopback-мост) — изменение сети, не выполнялось.
3. **Секрет**: сгенерировать токен, SHA-256 — в окружение Core (`PUBLIC_SEARCH_TOKEN_SHA256`), токен — в `ai-search.env` (`AI_LOT_CORE_URL`, `AI_LOT_CORE_TOKEN`).
4. Рекомендация: отдельная read-only роль PostgreSQL для этого эндпоинта (сейчас транзакция READ ONLY, но роль общая с API).
5. **Решение владельца по данным**: Core содержит лоты ЕФРСБ и ГИС Торги, живой обход которых отключён. Показ их карточек через Core — отдельное решение (юридическая проверка оферт всё ещё не проведена). В публичном тексте площадки не называются; хост ссылки виден на карточке.
6. Данные Core: см. ограничения качества выше (свежесть, регион 34%, срок 26%). Для широких запросов — частичный индекс по `lots((catalogue_data->>'asset_subtype'), id) WHERE canonical_status='APPLICATION_OPEN'` (ops-пакет, не выполнялся).
Активация после снятия блокеров: `AI_LOT_CORE_URL=http://<core>/api/v1/public-search`, `AI_LOT_CORE_TOKEN=…` в `ai-search.env`, `docker compose … up -d --force-recreate --no-deps ai-search`; откат — убрать две строки и пересоздать (поиск вернётся к живому web research).
