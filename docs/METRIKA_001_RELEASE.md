## Что в релизе
- `assets/analytics.js` — единый баннер «Настройки аналитики»: два независимых переключателя (Umami, Яндекс Метрика), по умолчанию выключены; «Принять всё», «Сохранить выбор», «Отказаться от всего». Кнопка «Настройки аналитики» добавляется в подвал каждой страницы и есть в /privacy/. Отзыв Метрики: удаляются cookie `_ym*` своего домена, страница перезагружается без загрузки сервиса. Скрипт подключён на всех 21 публичных страницах (раньше отсутствовал на 5).
- `assets/metrika.js` (в `<head>`, `defer`) — счётчик 113657048 грузится только после согласия на Метрику (ключ `ta_metrika_consent`; GPC/DNT = ноль запросов). URL и referrer без query/hash, `trackLinks:false`; Вебвизор, ecommerce, Тег Менеджер не используются. `<noscript>`-пиксель не используется (обошёл бы согласие). Kill switch: `METRIKA_ENABLED`.
- /privacy/ раздел 9 и перечень целей переписаны; /privacy/consent/ уточнён (аналитика — отдельный выбор). Версия согласия на заявку `2026-10-12.2` не менялась.
- `content/editorial/queue.json`: обновлён `content_sha256` страницы `blog/gosudarstvennye-i-municipalnye-torgi/` (добавлены только скрипты, текст статьи не менялся).
